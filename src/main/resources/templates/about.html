About BudgetBuddy AI

Intelligent Financial Transaction Categorization System

Overview

BudgetBuddy AI is an end-to-end autonomous transaction categorization system that uses machine learning to intelligently classify financial transactions into user-defined categories. Built with a production-ready architecture, the system eliminates third-party API dependencies while achieving high accuracy through advanced deep learning techniques.

The system transforms raw transaction strings (UPI narrations, bank descriptions) into structured categories using a fine-tuned DistilBERT multi-task model. Beyond categorization, BudgetBuddy provides proactive financial guidance—detecting spending patterns, analyzing trends, predicting future expenses, and sending intelligent nudges to help users make better financial decisions.
